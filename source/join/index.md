不管是不是正式社员，只要有想拍的东西，都可以投。

## 谁能投

社团成员——包括已经毕业的学长学姐，也包括还没入社的在校生。只要有视频创作的灵感和动力，就能投。

投稿身份分三种：

- 社员个人
- 社团小组
- 椿华动漫社

## 投什么

内容与 ACG、二次元相关，健康、无不良信息、传递正能量。以社团或小组名义发布的内容，需要有明确的主题。

| 类型 | 说明 |
| --- | --- |
| 宅舞 | 单人、多人、翻跳均可 |
| cosplay | 角色还原、剧情向、棚拍或外景 |
| 游戏 | 实况、集锦、对战记录 |
| 音游 | 手元、挑战、比赛 |
| 知识科普 | 动画、漫画、游戏相关的介绍与解读 |
| MAD / 短剧 | 剪辑、二创、小剧场 |

## 怎么投

把视频和材料私信给负责人或理事。

| 项目 | 要求 |
| --- | --- |
| 视频 | 成片文件 |
| 封面 | 与内容匹配的封面图 |
| 作品简介 | 活动简介、参演人员、活动时间；以社团或小组名义投稿时，需要较详细的活动介绍与活动总结 |
| 发布时间 | 有指定时间请备注，否则默认当天 20:00 发布 |
| 参演人员 | 可以联合投稿、蓝名 @、使用 cn；也可以隐藏信息（完全自愿） |

投稿前对照这份清单检查一遍：

- [ ] 视频已导出
- [ ] 封面已准备
- [ ] 作品简介写好了（活动简介、参演人员、活动时间）
- [ ] 是否指定发布时间
- [ ] 参演人员的署名方式已确认

## 审核与发布

1. 私信负责人或理事，把视频和材料交过去
2. 审核人数在 3 人或 3 人以上
3. 审核通过后，按约定时间发布

> 现阶段投稿量还不大，暂定私信社长即可。

## 关于收益

账号产生的收益归社团公用，也许会用来做奖励。激励机制还在完善，确定之后会写在这里。
